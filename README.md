# Агент за двадцать дней

Курс по агентным системам — подготовка к [HackAlem AI](https://astanahub.com) (23.09.2026, Астана).

Цель курса — **система**, а не чат с агентом: агентный цикл это один слой из девяти, и остальные восемь решают исход защиты.

## Что внутри

| Часть | Содержание |
| --- | --- |
| Каркас | восемь идей, на которых держится вся тема |
| Территория | тринадцать блоков — вся тема целиком, с привязкой к дням |
| Проектирование | девять слоёв системы, лестница форм, шесть шагов, каталог топологий, лист проектирования |
| Обвязка | харнес, правила, скилы, MCP, память — как одна шкала «когда попадает в контекст» |
| Метод | как вайбкодить агента: заказать → прочитать → сломать → понять |
| 20 дней | пять фаз, каждый день с заказом, проверкой и выводом; прогресс сохраняется в браузере |
| Домен | диспетчер Среднего коридора — сквозная практика на все двадцать дней |

## Стек

- **Next.js 16** (App Router, статический экспорт)
- **TypeScript** — весь контент типизирован в `src/types/course.ts`
- **Tailwind CSS v4** — CSS-first конфигурация в `src/app/globals.css`
- **shadcn/ui** на Radix — `NavigationMenu`, `Card`, `Table`, `Badge`, `Progress`, `Checkbox`, `Accordion`

Тема — тёмная, в духе Linear: near-black `#08090A`, индиго-акцент `#5E6AD2`, скругления 12px, мягкие тени, Inter.

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Статический экспорт попадает в `out/`. Для GitHub Pages сборка идёт с префиксом пути:

```bash
NEXT_PUBLIC_BASE_PATH=/agentic-course npm run build
```

## Деплой

`.github/workflows/deploy.yml` собирает и публикует на GitHub Pages при каждом пуше в `main`.
В настройках репозитория Pages должен быть переключён на источник **GitHub Actions**.

## Структура

```
src/
  app/          layout, страница, тема
  components/   секции, карточки дней, трекер прогресса
    ui/         компоненты shadcn/ui
  content/      весь текст курса, типизированный
  types/        модель контента
```

Содержание курса — предложение по подготовке, а не официальные материалы организаторов хакатона.
